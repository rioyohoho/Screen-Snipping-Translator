# Screen Snipping Translator

## 1. Download Source Code
1. Download: [rioyohoho/Screen-Snipping-Translator](https://codeload.github.com/rioyohoho/Screen-Snipping-Translator/zip/refs/heads/main)
2. Click the <> Code button -> Select Download ZIP.

## 2. Extract Files
Extract the downloaded .zip file into a folder on your computer.

## 3. Install in Browser
1. Open Chrome and paste the following URL into the address bar:
    - [chrome://extensions/](chrome://extensions/)
    - [edge://extensions/](edge://extensions/)
2. Enable Developer mode using the toggle switch in the top-right corner.
3. Click Load unpacked and select the extracted folder.
